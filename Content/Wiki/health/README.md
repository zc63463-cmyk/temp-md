# health/ 目录说明

> [!abstract] 用途
> Maintenance 的输出目录：记录断链、frontmatter 缺失、索引计数不一致、命名违规等问题，以及对应修复建议/修复记录。

## 文件命名
- `YYYY-MM-DD.md`

## 建议内容结构（模板）
1. 本次扫描范围（Domain/track/目录）
2. Broken links（未解析链接）
3. Frontmatter 完整性抽查
4. 索引一致性（Wiki/index vs 实际文件）
5. 修复记录（引用 [[Wiki/log]] 的对应条目）
