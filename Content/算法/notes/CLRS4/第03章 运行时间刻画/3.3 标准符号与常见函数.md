## 核心内容（学习记录）

> [!tip] 常用增长速度直觉（先写结论，后补证明）
> - 对数 < 多项式 < 指数 < 阶乘
> - 任意常数底的 log 只差常数倍

> [!example] 你自己整理一个“常见排序”
> $1 < \\log n < n^{0.5} < n < n\\log n < n^2 < 2^n < n!$

> [!warning] 易错点
> - ❌ 忽略对数底变化带来的“常数倍”
> - ✅ 记住：换底公式只差常数因子，对 O/Θ 不敏感
