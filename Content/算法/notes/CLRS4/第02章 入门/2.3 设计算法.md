## 核心内容（学习记录）

> [!def] 分治三步（你学习后补全）
> - Divide：{怎么分}
> - Conquer：{怎么解}
> - Combine：{怎么合并}

> [!tip] 归并排序的关键点
> - Merge 的线性合并
> - 递归式：T(n) = 2T(n/2) + Θ(n)

```cpp
// 归并排序（示意框架）
void mergeSort(vector<int>& a, int l, int r) {
  if (r - l <= 1) return;
  int m = (l + r) / 2;
  mergeSort(a, l, m);
  mergeSort(a, m, r);
  // merge(a[l..m), a[m..r))
}
```

> [!warning] 易错点
> - ❌ 把“分治”理解成只要递归就是分治
> - ✅ 分治强调“可分解 + 子问题结构相同 + 合并代价可控”
